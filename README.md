
# 🎓 Student Performance Analysis Dashboard | Power BI | MS Excel

## 📖 Overview

The **Student Performance Analysis Dashboard** is an interactive Power BI project that provides insights into students' academic performance by analyzing various educational, personal, and environmental factors. The dashboard helps identify trends affecting examination scores and supports data-driven decision-making for educators and institutions.

---

## 🚀 Project Objectives

- Analyze students' examination performance.
- Identify factors influencing exam scores.
- Compare student performance across different categories.
- Build an interactive dashboard for educational insights.
- Enable easy filtering and exploration of student data.

---

## 📊 Dashboard Features

 Exam Score Analysis
 Previous Score Comparison
 Teacher Quality vs Exam Score
 Parental Education Level Analysis
 Attendance Analysis
 Sleep Hours Analysis
 Internet Access Analysis
 Gender-wise Performance
 Student Improvement Analysis
 Interactive Data Table
 Dynamic Slicers and Filters
